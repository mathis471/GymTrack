# GymTrack – Version 1

Mobile-first PWA für einen persönlichen Trainingsplan.

## Funktionen
- Fest definierte Trainingspläne
- Übungen frei anlegbar
- Einheit pro Übung: kg, Scheiben, Körpergewicht oder Zeit
- Standard-Sätze und Ziel-Wiederholungen
- Training kann Übungen in beliebiger Reihenfolge enthalten
- Jede Übung hat pro Satz eigene Werte für Gewicht/Scheiben/Zeit und Wiederholungen
- Übungen können spontan zum aktuellen Plan hinzugefügt werden (Grundfunktion vorbereitet)
- Trainingshistorie lokal im Browser via IndexedDB
- Fortschrittsübersicht mit Verlauf
- JSON-Backup exportieren/importieren
- PWA-Grundstruktur

## GitHub Pages
1. Repository auf GitHub erstellen.
2. Alle Dateien dieses Ordners in das Repository laden.
3. GitHub: Settings → Pages → Deploy from branch → `main` / root auswählen.
4. Die angezeigte Pages-Adresse auf dem iPhone in Safari öffnen.
5. Teilen → „Zum Home-Bildschirm“.

Hinweis: Die Daten liegen lokal auf dem jeweiligen Gerät/Browser. Das Repository enthält keinen Trainingsverlauf.
